# Installation — IBIGENT Studio

**[Docs home](../../README.md)**

IBIGENT Studio is a **hosted service** — there is no separate program to install. “Installation” means subscribing and registering the MCP server URL in your AI tool.

## Requirements
- An active IBIGENT Studio subscription (https://www.ibigent.com/service/ibigent-studio.html).
- An MCP-capable AI tool: Claude, ChatGPT, Claude Code, Codex CLI, Cursor, or Antigravity.

## Set up
1. Subscribe to IBIGENT Studio on the official site.
2. Register the MCP server in your tool — see [MCP](mcp.md).

> No key is required. Once you register the URL, the IBIGENT sign-in page opens — sign in and click **Allow** once.
