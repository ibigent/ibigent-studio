## 준비물
- IBIGENT Studio 구독(활성, https://www.ibigent.com/service/ibigent-studio.html).
- MCP를 지원하는 AI 도구: Claude Code, Codex CLI, Cursor, Antigravity.

## 1단계 — 연결 방법 고르기
연결 방법은 두 가지입니다. **키 발급·복사는 필요 없습니다.**

| 방법 | 어떤 사람에게 | 도구 |
|---|---|---|
| **방법 A. 커넥터 연결** (Custom Connector) | 터미널을 쓰지 않는 분 (권장) | Claude, ChatGPT |
| **방법 B. 터미널 연결** (MCP server configuration) | 개발 도구를 쓰는 분 | Claude Code, Cursor, Codex, Antigravity |

## 2단계 — AI 도구 연결
아래 서버 주소를 등록합니다. 등록하면 아이비전트 로그인 창이 뜨고 **[연결 허용]** 만 누르면 끝입니다. 도구별 상세: [Claude Code](claude-code.md), [Codex CLI](codex.md), [Cursor](cursor.md), [Antigravity](antigravity.md).

```
https://mcp.ibigent.com/mcp
```

## 3단계 — AI로 제작
연결된 AI 도구에서 섹션 HTML을 만들어 IBIGENT Studio 편집 화면으로 보내도록 요청하고, 편집 화면에서 삽입 위치를 고릅니다. [예제](examples.md) 참고.
