# 예제 — IBIGENT Studio

**[문서 홈](../../README_ko.md)**

AI 도구에 IBIGENT Studio MCP를 연결한 상태에서, AI에게 HTML 제작을 요청해 편집기를 움직입니다.

## 기본 흐름
1. IBIGENT Studio에서 편집 화면을 엽니다.
2. AI 도구에 섹션을 HTML로 만들고 IBIGENT Studio 편집 화면으로 보내달라고 요청합니다.
3. 편집 화면에서 삽입 위치를 고르면 그자리에 HTML이 들어갑니다.

## 예시 프롬프트
```
반응형 "서비스 소개" 섹션을 카드 4개로 HTML로 만들어서
내 IBIGENT Studio 편집 화면으로 보내줘.
```

AI가 HTML을 생성하고 MCP 연결을 통해 편집기로 전달합니다. 삽입 위치는 사용자가 고릅니다.

## 코드 없이 말로 고치기 (비전트 AI 호스팅 · 빌더 호스팅)
편집 화면을 열어 둔 채 말로 지시하면 AI가 화면을 읽고 그 부분만 고칩니다. 코드는 필요 없습니다.

```
첫 화면 제목을 "따뜻한 공간, 이노디아" 로 바꿔줘
```

```
선택한 부분 글자색을 빨간색으로 바꿔줘
```

2~3초 뒤 편집 화면에 바로 반영되고 **[되돌리기]** 알림이 뜹니다. 마음에 들면 편집 화면에서 저장하세요(저장 전에는 실제 사이트에 반영되지 않습니다).

## 자료로 새 홈페이지 · 내용페이지 만들기
회사 소개·메뉴 구성·페이지별 글을 AI와 정리한 뒤 이렇게 말합니다.

```
회사 소개 자료로 홈페이지 새로 만들어줘
```

```
이 자료로 대표 인사말 페이지 만들어줘
```

자료가 편집 화면의 「새 홈페이지 제작」(빌더) 또는 「내용페이지 추가」 창에 채워집니다. 내용을 확인하고 [다음] 을 누르면 아이비전트 디자인으로 만들어집니다. 새 홈페이지를 만들어도 기존 게시판과 글은 그대로 남습니다. 내용페이지 추가는 내용페이지 편집 화면을 열어 두고 말하세요.

## 하위 메뉴 추가 (비전트 AI 호스팅 · 하위 페이지형)
```
진료 안내 메뉴 아래에 임플란트 페이지 추가해줘
```

## 내가 만든 사이트 올리기 (비전트 AI 호스팅 · ZIP)
1. AI 도구(Claude Code · Codex · Cursor 등)에게 사이트를 폴더로 만들게 한 뒤 폴더를 통째로 ZIP 으로 압축합니다. 압축 안에 `index.html` 필수 · 최대 100MB · PHP 등 실행 파일은 보안상 제외됩니다.
2. 편집 화면 오른쪽 아래 「사이트 배포」에 ZIP 을 끌어다 놓고 [업로드하고 배포] 를 누릅니다. ZIP 파일은 MCP 로 보낼 수 없어 직접 올려야 합니다.
3. 진행 막대가 끝나면 내 주소에 배포되고 편집 화면에도 반영됩니다. 기존 사이트 내용은 새 ZIP 으로 교체됩니다. 게시판 · DB 같은 기능이 필요하면 빌더 호스팅을 이용하세요.

올린 뒤에도 위처럼 편집 화면이나 AI 말로 고칠 수 있습니다. 저장해도 사이트의 스크립트는 그대로 남고, ZIP 으로 올린 뒤 처음 저장할 때 올린 원본이 「저장본 되돌리기」 목록에 보관됩니다. 편집 화면은 사이트의 스크립트를 실행하지 않아 언어 바꾸기 버튼 · 움직이는 슬라이드처럼 스크립트가 그리는 부분은 다르게 보일 수 있습니다 — 저장 버튼 옆 「실제 화면 미리보기」로 확인하세요.

편집기 화면 상세 단계는 공식 문서 참고: https://www.ibigent.com/docs/ibigent-studio/
